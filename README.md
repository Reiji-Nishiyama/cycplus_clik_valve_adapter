# CYCPLUS AS2 to Clik Valve Adapter

3D printable adapter for attaching a **Clik Valve** to the **CYCPLUS AS2** electric pump.

## Printing

To prevent air leakage, **print this adapter using a flexible filament** such as:

* TPU
* TPE

Using flexible materials helps create an airtight seal without additional parts.

### Using PLA or Other Rigid Filaments

If you print the adapter with a rigid filament such as **PLA**, **PETG**, or **ABS**, install **two O-rings** to prevent air leaks:

1. Between the **CYCPLUS AS2** pump and the adapter
2. Between the **adapter** and the **Clik Valve**

## Print Quality

The print quality of the **top and bottom sealing surfaces** is critical for maintaining an airtight connection.

For best results:

* Ensure the top and bottom surfaces are printed as smoothly as possible.
* Avoid under-extrusion, gaps, or rough surfaces.
* Verify the sealing surfaces are flat and free from defects before use.
